
# TextUtils

TextUtils is a simple and efficient web application built with React.js for performing common text manipulations. Whether you need to convert text to uppercase, lowercase, remove extra spaces, or count characters and words, TextUtils makes it easy!

## Features
- **Convert to Uppercase**: Convert all letters to uppercase.
- **Convert to Lowercase**: Convert all letters to lowercase.
- **Remove Extra Spaces**: Clean up any unnecessary spaces.
- **Reset**: Clear all changes and start fresh.
- **Word Count**: See the number of words in your text.
- **Character Count**: Count the characters in your text.
- **Preview**: Get a live preview of your text modifications.
- **Copy Text**: Easily copy your text to the clipboard.
